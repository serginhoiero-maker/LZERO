# Site LZerØ — versão inicial gratuita

Este é um site estático responsivo para a banda LZerØ, feito em HTML, CSS e JavaScript simples. Não precisa de créditos de IA para editar e pode ser publicado em hospedagem estática gratuita.

## Arquivos
- `index.html` — conteúdo e seções do site
- `style.css` — identidade visual e responsividade
- `script.js` — menu mobile e links de redes sociais

## Personalizar antes de publicar
1. Abra `script.js`.
2. Substitua os valores vazios em `LZERO_LINKS` pelos links oficiais da banda:
   - `instagram`
   - `youtube`
   - `spotify`
3. Ajuste o e-mail de contato se necessário.
4. Troque as artes abstratas por capas oficiais e fotos da banda quando tiver os arquivos. O design atual usa composições CSS para evitar imagens inventadas ou fotos alteradas.

## Publicar gratuitamente pelo GitHub Pages
1. Crie uma conta em https://github.com/ (se ainda não tiver).
2. Crie um repositório público, por exemplo `site-lzero`.
3. Envie os três arquivos (`index.html`, `style.css`, `script.js`) para a raiz do repositório.
4. No GitHub, abra **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`, depois salve.
6. Aguarde a publicação. O GitHub mostrará o endereço público nas configurações de Pages.

## Observações
- Esta versão é uma base funcional; não está conectada ao Emergent nem importa automaticamente os arquivos dele.
- Não inclui datas fictícias de shows. A agenda mostra “Novas datas em breve”.
- Os botões de streaming e redes precisam dos links reais para funcionar.
- O e-mail padrão `contato@lzero.com.br` é apenas um valor inicial; substitua se não for seu endereço real.
